### Anomalon

In physics, an anomalon is a hypothesized particle fragment that exhibits an anomalously large reaction 
cross-section — meaning it interacts far more powerfully with its environment than a normal particle. 

For a C++ engine powered by Boost.Beast and Lua, it is a perfect metaphor: 
a highly reactive, high-performance core that handles massive network throughput with zero friction.

More background on [Anomalon](https://github.com/rburkholder/anomalon)

anomalon is referenced in:
* [viessmann](https://github.com/rburkholder/viessmann/blob/master/main.cpp) - serves a lua generated web page for logging into viessmann api
* [tangle](https://github.com/rburkholder/tangle/blob/master/src/main.cpp) - web site driven with lua generated pages
